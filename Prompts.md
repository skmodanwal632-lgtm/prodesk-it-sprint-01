# AI Development Log — Prodesk IT Sprint 01

This file records the AI assistance used during development, as required by the sprint policy.

## Prompt 01 — Initial architecture
> Build a professional Prodesk IT landing page using semantic HTML, raw CSS Flexbox/Grid and vanilla JavaScript. Include a responsive navbar, hero section, three service cards and footer. Do not use Bootstrap or other UI frameworks.

## Prompt 02 — Responsive design
> Make the landing page fully responsive for desktop, tablet and mobile. Use CSS Grid/Flexbox and implement a mobile hamburger navigation without a UI framework.

## Prompt 03 — UI/UX enhancements
> Add a vanilla JavaScript dark/light mode toggle by applying a dark class to the body, CTA hover interactions, service-card lift effects and sticky navigation.

## Prompt 04 — Glassmorphism
> Apply a restrained frosted-glass effect to the sticky navigation using backdrop-filter while preserving readability and accessibility.

## Prompt 05 — Sprint documentation
> Create a README with project structure, local setup, deployment instructions, QA checklist, live URL placeholder and screenshot placeholder.
